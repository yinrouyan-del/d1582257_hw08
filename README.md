## 三、問題回答

### 問題一：為什麼 `"4"` 要先轉成數字，才能用於本題的分攤計算？
**回答：**  
在 Python 中，帶有引號的 `"4"` 屬於**字串 (string, `str`)** 型別，而分攤費用需要執行數學除法運算（`/`）。Python 不允許對數值與字串直接進行除法運算（例如 `1220.0 / "4"` 會引發 `TypeError` 錯誤）。因此，必須先使用 `int("4")` 將文字轉換為**整數 (integer, `int`)** 型別，才能順利進行算術運算。

---

### 問題二：如果先扣折價券，再依剩餘餐費計算服務費，第一組的應付總額會變成多少？為什麼和題目規定的結果不同？
**回答：**  
若先扣除折價券再計算服務費，第一組的計算過程如下：
1. 折扣後剩餘餐費：$1,200 - 100 = 1,100$ 元
2. 服務費：$1,100 \times 0.10 = 110$ 元
3. 應付總額：$1,100 + 110 = 1,210$ 元

**原因分析：**  
兩者相差 10 元。這是因為題目的商業規則要求「服務費必須以**原始餐費**計算」，也就是以全額 $1,200$ 元的 10%（$120$ 元）計收；若先扣除折價券，服務費的計算基準基數減少了 100 元，連帶使服務費少收了 $100 \times 10\% = 10$ 元，導致最後的應付總額不同。
